# AniLedger

AniLedger is an anime and manga tracker for iPhone and iPad. Browse the catalog, track progress on MyAnimeList, follow friends’ public activity, and read title reviews in the app.

- [iOS setup and release guide](ios/README.md)
- [iOS releases](https://github.com/jacobxhoang/ani-ledger/releases)

The iOS app connects directly to MyAnimeList, Tenrai, and Jikan Edge.
